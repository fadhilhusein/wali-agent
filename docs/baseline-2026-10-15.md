## Catatan agar angka ini tidak salah dibaca

- **Satu run saja.** Model tidak memberi jawaban identik di tiap run (C61). Fase 8 memakai `--repeat 3`.
- **Forecast tidak persis ground truth.** Saldo terendah -6.530.874 dibanding -6.681.668 pada
  `data/seed/ground_truth.json`. Tanggal dan jumlah hari di bawah nol sama. Selisihnya sesuai C23.
- **`MANUAL_MINUTES_PER_ITEM` masih placeholder** (U5), jadi `minutes_saved_estimate` bukan angka
  yang boleh dikutip.
- **Model ini mungkin bukan model demo final.** Model sebelumnya (`gemini-3.8-flash`) kena
  503, dan `gemini-3.5-flash` gagal tool calling karena `thought_signature` plus kuota free tier.
  Ganti model berarti baseline ini perlu diulang.
- **Latensi:** rekonsiliasi sekitar 29 detik dan forecast sekitar 45 detik pada live-check.
