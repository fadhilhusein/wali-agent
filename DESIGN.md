# Wali Web Design Direction

This file describes the original static Python demo. The current Next.js workspace follows the user-approved Paper frames, documented in [frontend/DESIGN.md](frontend/DESIGN.md).

## Design Read

Wali is a financial-assistant workspace for small-business operators. The interface uses English
copy and a calm, operational visual language. Dial: ENERGY 2 / RHYTHM 2 / MOTION 1.

## Identity

- Warm ivory creates a paper-ledger atmosphere without using a decorative grid.
- Charcoal keeps financial information readable and avoids a sterile pure-black treatment.
- Forest green marks primary actions because it connects approval with controlled financial work.
- Amber appears only for simulation and risk warnings, so it retains meaning as an alert.
- Georgia is reserved for the wordmark and major headings to give Wali an editorial identity.
- The system sans-serif stack keeps dense operational details readable without external font requests.
- Thin ledger-like rules group related facts and reinforce the financial-workspace identity.

## Composition

- The conversation is the primary work surface and receives the only elevation shadow.
- The approval queue is a flatter review rail so confirmation remains visible without competing
  with the composer.
- Quick prompts use three functional rows on desktop and a single vertical sequence on mobile.
- Desktop, tablet, and mobile use distinct layout states based on where the content stops fitting.

## Interaction

- Motion is limited to short hover, focus, and state transitions.
- Reduced-motion preferences stop decorative movement.
- Every control has a real action and a minimum 44 pixel touch target.
- Loading, empty, error, and processing states always include explanatory text.

## Boundaries

- Light theme only, as explicitly selected for this work-oriented demo.
- No gradients, glow, glassmorphism, decorative status dots, or looping hero animation.
- No fabricated metrics, testimonials, customer names, or product capabilities.
- Dynamic values are inserted as text, never HTML.
