# Wali Paper chat audit

Date: 2026-10-15. Mode: after, selected by the user for this session.

## Result

No actionable findings remain within the approved chat and shared-shell scope. The audit uses the supplied Paper React exports as the visual direction and the user's explicit choices: Wali, English, shared sidebar, and disabled future-feature placeholders.

## Evidence

- Desktop home and conversation screenshots were compared with the supplied reference: 280 px sidebar, 72 px header, 760 px composer, pale input surfaces, four gradient prompts, right-aligned user messages and unboxed assistant replies.
- Phone home and long-conversation screenshots were inspected; the cards reflow, the transcript has its own scroll container, and input remains outside that scroll container.
- The browser regression script checks 14 groups of scenarios, including five viewport widths, keyboard focus, nested dialogs, errors, role changes, blocked replies, Copy, mandate and approval actions, and scroll-follow behavior. Its API responses are mocked and clearly labeled as test data.
- Fifteen text color pairings are checked using WCAG relative luminance; ratios and thresholds are saved in `frontend/test-results/results.json` when the script runs.
- Disabled controls expose Coming soon in accessible names and visible contextual labels. No unsupported control calls an API, and no sample Nova history, user identity, model name, or financial result is inserted into the product.
- The backend, proxy, provider, and original approval/mandate components retain their contracts. New chat only navigates after a successful API reset.

## Verification boundaries

Google Sans is not bundled; the approved Arial fallback was used for screenshots. Response rendering preserves plain-text whitespace and does not add a Markdown parser. UI tests intercept API traffic and do not assess live model answers or real backend execution. Narrow and short viewport checks cover reflow and available input height; a physical phone keyboard and native browser zoom were not exercised. Existing Python/static-demo styling is outside this audit.

No additional audit fixes require a user selection. Full gate evidence is recorded in `frontend/DELIVERY-GATE.md`.
